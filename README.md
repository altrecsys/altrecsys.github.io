# AltRecSys web site

This web site is built with [Zola][] and the [Academic Workshop theme][theme].

Software is installed with [Mise][].  To set up the environment and start previewing
the site:

```console
$ mise install
$ mise run dev-server
```

[Zola]: https://www.getzola.org/
[theme]: https://github.com/aterenin/academic-workshop
[Mise]: https://mise.jdx.dev/
